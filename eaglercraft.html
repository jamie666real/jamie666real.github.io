About Eaglercraft

Eaglercraft allows you to play Minecraft directly in your web browser without needing to download the game. It's perfect for quick sessions or playing on devices where installing Minecraft isn't possible.

Server WebSocket URL

wss://lunar-mc.eagler.host

How to Connect

  1. Go to an Eaglercraft client website (search for "Eaglercraft" online)
  2. Enter the WebSocket URL above in the server address field
  3. Click connect and start playing!

Note: Make sure you're using a compatible Eaglercraft client that supports WebSocket connections.
